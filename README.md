# My To-Do List

Aplikasi To-Do List responsif menggunakan HTML, CSS, dan JavaScript.

## Cara menjalankan di Visual Studio Code
1. Ekstrak folder ini.
2. Buka VS Code, pilih **File > Open Folder...**, lalu pilih folder `todo_list_vscode`.
3. Buka `index.html`.
4. Jalankan melalui browser. Disarankan memasang ekstensi **Live Server**, lalu klik kanan `index.html` > **Open with Live Server**.

## Struktur
- `index.html`: struktur halaman.
- `style.css`: tampilan dan responsivitas.
- `script.js`: logika tugas, profil, filter tanggal, dan localStorage.

Data disimpan di localStorage browser yang digunakan, bukan di server.
